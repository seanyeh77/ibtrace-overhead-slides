## 第 5 張：判準：下界超過 3 % 才算有空間

收益是 1 減去改後時間除以預設時間。區間用 log 時間的 Welch t 檢定算 95 % 信賴區間。3 % 約是對照組雜訊的上限。估計值要落在實測的 0.5–1.5 倍，才算估得準。

出處：同上 §5；repo `e1/part2/ROWS.json` 的 `statistics`。

## 第 6 張：一台機器有 8 個 NUMA node

創進一號的節點開啟 SNC4，兩顆 CPU 各切成 4 個 NUMA node，每個 node 14 顆核心。網卡 mlx5_0 掛在 node 1，也就是 CPU 14–27；這一點每個 job 開跑時都會從 sysfs 檢查。其他 node 的 CPU 編號是照每個 node 連續 14 顆推的。

出處：`ROWS.json` 的 `cluster.node_check`。

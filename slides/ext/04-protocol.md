# 健康檢查的六項測試

| 測試 | 量什麼 | 不合格的條件 |
| --- | --- | --- |
| 系統狀態 | /dev/shm、NUMA、8 個 port | 任一項異常 |
| 延遲 | 8 B 的單向延遲 | 超過參考值 1.5 倍 |
| 每張網卡的頻寬 | 8 張卡逐一測 | 低於參考值 0.9 倍 |
| 兩節點 alltoall | 1 MiB，2 與 8 條 rail | 超過參考值 1.25 倍 |
| 四節點 alltoall | 同上，加上 4×4 配置 | 超過參考值 1.25 或 1.5 倍 |
| 每對節點的傳輸 | 1 MiB，8 條 rail | 超過其他節點的 1.2 倍 |

::note::

<Note :notes="[
  ['參考值來自 12 個正常節點（3 個 job），門檻先寫死再量。', '不合格的節點排除，整個 job 作廢重送。'],
]" />

# 計分規則：收資料前就寫死

| 規則 | 內容 |
| --- | --- |
| 指標 | 誤差、方向正確、兩種排第一，與第二版相同 |
| 比較對象 | 第一版、第二版、第三版、counter 與 profiler 做法 |
| 不預測 | 算成 0 ms，不排除 |
| 在途數的三項設定 | 只給方向，不計分 |
| 程式的時間 | 只用 ibtrace 記錄的時間，不讀程式的輸出 |
| 模型檔案 | 評估前比對定版時的檢查碼 |

::note::

<Note :notes="[
  ['已知的雜訊：正常節點在 8 條 rail 時偶爾慢 32–130 µs。', '所以 rail 數這一類的實測 ΔT 雜訊較大。'],
]" />

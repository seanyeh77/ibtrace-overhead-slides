# 限制與第四版的方向

| 問題 | 第四版的做法 |
| --- | --- |
| 迴圈只看每週期 8 次呼叫 | 放寬上限，用時間步對齊 |
| rail 數沒有固定的啟動成本 | 加入啟動成本，允許預測變慢 |
| 背景流量提早啟動 | 每個狀態啟動前等一樣久 |
| 對照組不是 0 也照樣計分 | 對照組偏離 0 就先停下檢查 |
| 每次執行只有 1–2 s | 至少一組用較長的執行驗證 |
